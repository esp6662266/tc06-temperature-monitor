# 검증 상태 · v0.1.0

확인일: 2026-10-15 (한국시간). 이 문서는 실제로 확인한 범위만 표시한다.

## 현재 완료

- macOS 개발 환경에서 Python/Tesseract 자동 시험 10개.
- Node API 자동 시험 8개: 공개 무인증 조회·업로드, 중복 방지, 과거 재전송, 동시 최신값 갱신, 오래된 값 표시, 형식 검사, 한국 날짜별 CSV, WAV 해시 재사용.
- 설치된 Chrome에서 Playwright 브라우저 시험 5개: 정상/오래됨/실패/단절 표시, 키 없는 공개 페이지, 1분 음성 호출과 정지, 실제 로컬 HTTP 업로드→표시, 단절 시 캐시된 안내 음성 선택.
- 브라우저 음성 호출 시험은 오디오 재생 메서드를 대체해 호출 흐름과 파일 선택을 검증했다. **실제 여성 음성을 들은 시험이 아니다.**
- 사용자가 제공한 정지 이미지에서 실제 Tesseract로 TC-06 라벨과 옆 숫자가 원본 표시와 일치하는 것을 확인했다. 정지 이미지이므로 `freshness_unverified`로 처리하고 정상 현재값으로 올리지 않았다. 원본과 판독 이미지·운전 기록은 공개 저장소에 넣지 않았다.
- 합성된 OCR 이미지에서 위치 이동·크기 변경·중복 라벨·가림·원본 시계 진행/정지 판정을 확인했다. 실설비 시뮬레이터는 만들거나 실행하지 않았다.
- 1920×1080 Chrome 화면에서 합성 예시를 사용한 레이아웃 확인. 실제 설비값이 아니라는 표식을 붙여 검토했으며 가로 넘침이 없었다.
- Python 구문 컴파일 및 JavaScript 구문 확인.
- 개발 검증 환경: Python 3.9.6, Tesseract 5.5.3, Node.js 25.5.0. 현장 권장 설치는 Python 3.12, 서버 대상은 Node.js 22이며 해당 환경의 실기 검증은 별도다.
- 고정한 Python 의존성의 Windows 64비트/Python 3.12용 배포 파일을 실제 다운로드해 패키지 제공 여부를 확인했다. Windows 설치·실행 성공을 의미하지 않는다.
