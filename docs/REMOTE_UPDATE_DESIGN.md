# TC-06 현장 PC 저영향 원격 업데이트 설계 (1단계)

상태: 설계 확정 / **원격 업데이트 기능 미구현**. 이 문서만 추가한 것으로 현장 PC에 변경은 없다.

## 사용자 요구
- GitHub 소스 수정 후 Windows 배포물 빌드; 관리자가 웹에서 **업데이트 실행**을 눌러야만 적용.
- HMI·PLC·Windows 재부팅·기존 운전 프로그램을 건드리지 않음.
- 다운로드·SHA-256 검증은 OCR 수집기를 실행한 채 수행.
- OCR 실행 코드가 바뀔 때에만 수집 프로세스 단독 재시작. 설정·웹 변경은 가능하면 무재시작.
- 실패 시 이전 검증된 버전으로 롤백하고, 업데이트 상태/측정 공백을 명확히 표시.

## 중요 제약
- 현재 `docs/NETLIFY_SETUP.md`에 따르면 Netlify는 **GitHub 자동 배포 미연결**이며 CLI 수동 배포. GitHub push만으로 운영 웹이 바뀌지 않는다.
- 현재 `.github/workflows/windows-installer.yml`은 `workflow_dispatch` 수동 빌드이며 14일 보존 artifact만 만든다. 현장 PC용 공개/인증된 버전 매니페스트 배포 단계가 없다.
- 현재 온도 API는 공개·무인증이다. **업데이트 명령을 기존 공개 API에 추가하지 않는다.** 업데이트 전용 인증된 관리자 경로가 필요하다.
- 서버리스 Netlify Functions는 현장 PC에 직접 연결을 유지하지 않는다. 현장 에이전트가 서버에 **명령 상태만** 주기적으로 조회한다. 조회는 업데이트 실행이 아니다.
- 현장 HMI와 동일 PC 설치는 위험평가 및 현장 승인 후 진행. 가능하면 별도 캡처 PC 우선.

## 구현 순서
1. **배포 파이프라인:** 보호된 release tag 또는 수동 승인 workflow에서 Windows 설치판을 빌드·시험하고, 불변 버전·파일 SHA-256·다운로드 URL을 서명된 매니페스트로 게시. 기존 수동 workflow를 임의로 운영 자동 배포로 바꾸지 않는다.
2. **업데이트 전용 인증:** Netlify Identity 등 지원되는 신뢰할 수 있는 인증 제공자와 서버 측 권한 검증. 관리자의 버튼 요청에는 CSRF 방어, 요청별 nonce, 만료시간, 감사 기록, 속도 제한을 적용. 비밀키를 공개 웹 JS나 GitHub에 넣지 않는다.
3. **현장 경량 에이전트:** 로그인 후 사용자 권한으로 실행되는 별도 프로세스. 서버 명령 조회, 고정된 공식 배포 URL만 허용, 서명/해시 검증, 다운로드 속도/디스크 여유 확인, 준비 폴더에 저장. 임의 명령 실행이나 임의 URL 다운로드 금지.
4. **원자적 교체:** 준비 완료 후 수집기만 정지 → 새 버전 실행 → 정상 기동·OCR 준비·서버 연결 확인. 실패/시간 초과 시 이전 버전 재기동. 로컬 설정/SQLite는 보존하고 데이터 마이그레이션은 별도 검증.
5. **상태 표시:** 미배포/대기/다운로드/검증/교체/정상/롤백/실패를 구분. 웹에는 현장 PC 마지막 응답 시각, 현 버전, 목표 버전, 업데이트 요청자/시각을 표시. 데이터 수집 중단 시간은 실측으로 기록.
6. **현장 도입:** 테스트 Windows PC에서 무권한 실행·중단/복구·전원 차단·네트워크 장애·잘못된 서명·이중 클릭·다운그레이드 차단을 시험한 후 현장에 최초 1회 설치.

## 적용 원칙
- 업데이트는 **관리자 명시적 버튼 클릭** 없이는 절대 실행하지 않는다. 단, 별도 테스트 환경의 배포/검증은 가능하다.
- 업데이트 과정에서 Windows 재부팅, HMI 창 조작, PLC 통신/제어를 하지 않는다.
- CPU·디스크 영향 0과 OCR 수집 완전 무중단은 보장하지 않는다. 수집 프로세스 교체 시 짧은 공백이 발생할 수 있다.
- 실패/미응답 상태를 성공으로 표시하지 않는다.
- 웹 UI를 먼저 공개해 작동하는 척하지 않는다. 인증과 현장 에이전트가 검증된 뒤 버튼을 활성화한다.

## 구현 전 확인 사항
- HMI와 같은 PC인지, 별도 캡처 PC인지
- Windows 계정의 설치 권한과 보안 정책
- 관리자 인증 제공자 및 업데이트 매니페스트 배포 위치
- 현장 PC에서 GitHub Release 다운로드 접근 가능 여부

이 문서는 향후 구현의 안전 경계를 기록하며 기존 OCR·웹·API 동작을 변경하지 않는다.
