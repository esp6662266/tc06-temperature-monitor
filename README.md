# TC-06 온도 OCR · 현장 음성 모니터

윈도우 PC의 HMI 영상에서 **TC-06 표시 온도**를 읽고, **1분마다 서버에 저장**합니다. 현장 TV 브라우저에서는 온도를 크게 표시하고 한국어 여성 음성으로 **“현재 온도는 … 도입니다.”**를 1분마다 안내합니다.

**현재 버전: 0.2.0. Netlify 사이트 배포 완료 / Windows 현장 검증 전.** 윈도우 실기 실행·EXE 빌드·실제 TV 음성 재생은 아직 확인하지 않았습니다. 아래 문서를 다른 PC의 Codex에 전달하면 설정과 검증을 이어갈 수 있습니다.

## 접속 주소와 화면

- **숫자 전용 디스플레이:** https://tc06-temperature-monitor.netlify.app/
- **일반 화면 · 설정:** https://tc06-temperature-monitor.netlify.app/?mode=normal
- **수집 PC 서버 주소:** `https://tc06-temperature-monitor.netlify.app` (GUI 기본값에 포함)

홈페이지는 검은 배경에 숫자만 표시합니다. 화면 클릭·터치 또는 리모컨 Enter로 메뉴를 열고 **음성 시작 / 전체 화면 / 일반 화면**을 선택합니다. Esc로도 일반 화면에 돌아갑니다. 메뉴는 조작 후 5초가 지나면 숨겨집니다. CSS가 화면을 채우며 브라우저 주소창까지 숨기는 전체 화면은 조작이 필요할 수 있습니다.

첫 접속·인터넷 단절·최근 판독 없음·판독 실패·캡처 후 150초 초과 때는 **38**을 표시하고 **“현재 온도는 삼십팔 도입니다.”**를 한국어 여성 음성으로 안내합니다. 일반 화면에 **기본값 · 38도**와 사유를 표시합니다. 이 38도는 서버에 실제 측정 기록으로 생성하지 않습니다. 정상 수신 후에는 수집기가 보낸 실제 값과 해당 음성으로 전환됩니다.

음성 시작을 한 번 누르면 즉시 안내하고 기본 1분마다 반복합니다. 일반 화면에서 음량·반복 간격(1/2/5분)·색상 조합(현장 추천 7가지·직접 선택)·크기를 바꾸며, 이 기기의 브라우저에 저장됩니다. 브라우저가 허용하지 않는 무조작 소리 재생을 강제하지 않습니다.

오프라인 페이지·38도 음성은 **온라인으로 한 번 정상 방문하고 서비스 워커 캐시가 저장된 브라우저**에서 사용할 수 있습니다. 캐시 삭제·시크릿 모드·서비스 워커 미지원 TV에서는 오프라인 첫 접속을 보장하지 않습니다. 실제 온도 API 응답은 오프라인 캐시로 현재값처럼 사용하지 않습니다.

## 구성

```text
HMI 영상
  ├─ 캡처보드 원본 직접 읽기 (권장)
  └─ 지정한 창의 보이는 영역 읽기 (이동·크기 변경 추적)
              ↓
Windows 수집기: 로컬 OCR · 원본 시계 확인 · SQLite 기록/재전송
              ↓ HTTPS, 1분마다
Netlify Functions + Blobs: 공개 수신 · 기록 저장 · 최신값 순서 보호
              ↓
현장 TV: 브라우저 화면 · 한국어 여성 음성 파일 재생
```

- 외부 AI API와 유료 OCR/TTS API를 호출하지 않습니다. 로컬 Tesseract와 Windows에 설치된 한국어 여성 음성을 사용합니다.
- 실제 값은 Windows가 만든 WAV 파일을 재생합니다. 기본값 38도는 동봉된 Yuna 한국어 여성 MP3를 사용합니다. 실제 값의 파일이 없을 때는 알려진 한국어 여성 음성이 기기에 있는 경우에만 브라우저 음성으로 보완합니다.
- 서버 호스팅·함수 호출·저장소 사용량은 Netlify 요금제에 따릅니다. 무료 무제한을 보장하지 않습니다.
- PLC에 접속하거나 HMI를 조작하는 기능이 없습니다. 영상 표시값의 참고 감시 도구이며 설비 보호·인터록·비상 경보를 대체하지 않습니다.

## 구현된 기능

| 영역 | 내용 |
|---|---|
| 입력 | 캡처보드 번호 또는 정확한 창 제목 선택 |
| 추적 | 지정 영상 안에서 `TC-06` 라벨과 오른쪽 회색 온도칸을 다시 탐색 |
| 판독 | 약 2초 간격, 소수점 한 자리 검사, 두 전처리 결과 비교 |
| 신선도 | 화면 상단 원본 시계의 진행 확인. 최초 시계 진행 전에는 정상값으로 보내지 않음 |
| 저장 | 첫 정상 판독 확인 후 즉시 저장, 이후 약 60초 간격. 정상 판독이 60초간 없으면 실패 상태 기록 |
| 단절 | 로컬 SQLite에 보관하고 복구 후 재전송. 같은 id 중복 저장 방지 |
| 최신값 | 신규 기록 우선 전송, 서버 ETag 조건부 갱신으로 오래된 기록의 덮어쓰기 방지 |
| 음성 | Windows 한국어 여성 음성 → WAV 생성·캐시. 같은 음성은 서버에서 재사용 |
| 웹 | 온도만 전체 화면, 일반 설정 화면, 대비색 7종·직접 색상, 크기·음량·음성 주기, 초기/오프라인 기본 38도 |
| 기록 | 한국시간 날짜별 CSV 다운로드 |
| PC 운영 | GUI, 판독 영역 미리보기, 회전 로그, 자동 재연결, 선택적 시작프로그램 등록 |
| 접속 | 조회·업로드 모두 키와 로그인 없음. 서버/영상 설정 후 실행 시 자동 수집 |

## 사용 범위와 제한

- **지정한 HMI 영상 안에서** 추적합니다. 바탕화면의 아무 숫자나 온도로 읽지 않습니다.
- 창 방식은 **보이는 화면 캡처**입니다. 옆에 다른 창이 있는 것은 가능하지만, TC-06 또는 원본 시계가 가려지거나 HMI 창이 최소화되면 정상 판독을 보장하지 않습니다. 이때 판독 불가로 처리합니다. 가림 판정은 픽셀 격자 표본이므로 모든 투명 오버레이를 완벽히 검출한다고 주장하지 않습니다.
- 캡처보드 직접 입력은 미리보기 창 위치와 무관합니다. 캡처 장치가 다른 앱에 독점되면 해당 앱을 종료하거나 장치 공유 구성을 실제 확인해야 합니다.
- 첨부된 HMI처럼 **검은 라벨 + 바로 오른쪽의 회색 숫자칸 + 오른쪽 단위 + 화면 상단 시계**를 대상으로 합니다. 다른 테마·배치·아주 작은 창은 OCR 프로필 수정이 필요합니다.
- 화면 상단에 단 하나의 `시:분:초`가 검출되어야 합니다. 시계가 약 15초 정지하면 `stale_source`입니다. 이는 영상 진행 확인이며, 원본 HMI의 PLC 통신 품질까지 증명하지 않습니다.
- 웹은 캡처 후 150초를 넘긴 값, 통신 실패, 정상 이외 판독 상태에서 사용자 지정 기본값 38도를 표시·안내하며 일반 화면에서 실제 수신값과 구분합니다. 이 시간은 운영 목적에 맞게 현장 검증 후 조정합니다.
- 음성은 페이지를 열고 **‘음성 안내 시작’**을 눌러야 할 수 있습니다. 이는 로그인 조건이 아닌 브라우저 자동재생 정책입니다. 실제 TV의 WAV·JavaScript·자동재생 지원을 확인해야 합니다. 백그라운드 탭·절전 상태에서 60초 타이머의 정확한 실행을 보장하지 않습니다.
- PC 절전·종료 중에는 측정하지 않습니다. 복귀 후 빠진 분의 온도를 추정해 채우지 않습니다.
- 기본 GUI는 단일 수집기만 실행하세요. 한 사이트는 한 대의 수집 PC/TC-06을 대상으로 합니다.
- 이력 자동 삭제는 하지 않습니다. 보관 기간·백업 정책과 Netlify 사용량을 운영 전에 정하세요.

## 개발 검증

Python 3.12 권장, Node.js 22 이상. Windows EXE는 Windows에서만 빌드합니다.

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
npm ci
npm test
npm run test:web
```

웹 시험은 설치된 Chrome을 사용합니다. Chrome이 없으면 Playwright 설정을 환경에 맞춰 변경해야 합니다. 테스트 화면의 수치는 합성된 예시이며 실설비 운전 데이터가 아닙니다.

## 공개 저장소에 포함하지 않는 것

실제 운전 화면, 온도 기록, 사용자별 설정, 수집기 음성 캐시, 빌드 중간 파일은 `.gitignore`로 제외합니다. 온도 사이트와 수신 API는 사용자 요청에 따라 모두 공개·무인증입니다. 서버 주소만 알면 조회와 업로드가 가능합니다. `web/audio/fallback-38.mp3`는 고정 기본값 안내용 배포 자산입니다.

일반 화면의 **전체 화면** 버튼도 숫자 전용 모드로 전환한 후 전체 화면을 요청한다. 온도 이외의 제목·상태·단위·설정은 숨겨지고, 화면/리모컨 조작 때만 메뉴를 잠깐 표시한다.

현장 색상 미리보기 7가지: 검정/흰색, 검정/노랑(추천), 검정/민트, 검정/하늘색, 검정/주황, 남색/흰색, 노랑/검정. 앞은 배경, 뒤는 숫자색이다. 밝은 대비를 기준으로 고른 디자인이며 실제 현장 조명·거리·TV에서 최종 선택한다.
