# 짧은 OCR 실패의 표시용 추정 · 웹/API v0.5.2

Windows 수집기/설치판은 0.5.0 그대로 사용한다. 홈페이지 새로고침으로 적용한다. 추정은 실제 영상을 복원하거나 부분 판독 문자를 얻는 기능이 아니다. 마지막 정상값 유지 정책 위에 조건부로 추가한 표시 기능이다.

## 적용 조건

- 최근 6분 안에서 같은 수집 PC의 정상 기록을 캡처 시각 순으로 비교한다. 최근 연속 구간의 3~5개를 사용하며 기록 간격은 30~90초여야 한다.
- 인접 기록의 분당 변화량 중앙값을 사용한다. 각 변화량과 중앙값의 차이가 `max(0.5도/분, 중앙값 절댓값의 20%)` 이내일 때만 추정한다. 이 기준은 보수적인 표시 규칙이며 현장 정확도나 설비의 물리 변화율을 보장하는 기준이 아니다.
- 현재 추정은 마지막 정상값보다 나중에 캡처된 OCR 실패가 실제로 접수됐을 때만 제공한다. 대상은 `ocr_failed`, `value_suspect`, `low_confidence`, `anchor_missing`, `ambiguous_anchor`, `occluded`다.
- `source_error`, `stale_source`, `freshness_unverified`, `window_missing`, 업로드 없음은 추정하지 않는다. 다른 PC의 기록을 섞거나 미래의 정상값으로 과거 추정을 보강하지 않는다.
- 마지막 정상 캡처부터 최대 120초까지만 유효하다. 120초 초과, 자료 부족, 불규칙한 추세, 허용 숫자 범위(-9999.9~9999.9) 초과는 마지막 정상값 표시로 돌아간다. 온도가 갑자기 변하는 상황을 알아낼 수 없다.

예시: 실제 기록 590 → 595 → 600도와 그 다음 분의 OCR 실패가 있으면 약 605도를 별도 추정할 수 있다. 예시는 합성 데이터다. 실패를 정상 605도로 바꿔 저장하지 않는다.

## API와 저장

`GET /api/latest`의 기존 `record`, `last_good`는 유지한다. 별도 `estimate`는 아래 정보를 반환하거나 null이다.

- `estimated: true`, `method: recent_linear_v1`, `value_c`, `estimated_at`
- `based_on_at`, `based_on_value_c`, `last_normal_id`, `expires_at`
- `sample_count`, `slope_c_per_minute`, `device_id`

추정 조회 실패는 실측 조회를 막지 않으며 estimate만 null로 돌려준다. 추정값을 `records`, `latest`, `last-good`에 저장하지 않는다. `GET /api/history` CSV에도 추가하지 않는다. 기존 수집기의 실패 원본은 status와 null을 유지한다.

그래프 색인 v2는 기존 튜플 끝에 device_id를 추가한다. 이전 색인은 canonical records를 한 번 읽어 장치 정보를 보강하며, 동시 업로드는 ETag 병합으로 보존한다. 보관 기간은 같은 한국 날짜 30일이다.

## 웹과 그래프

- 숫자·일반·그래프 상단에 `≈605.0`과 `추정값 · 마지막 실측 N분 전`을 표시한다. 메타데이터에는 원래 정상 판독 시각을 유지한다.
- 값은 API 조회 시각의 추정이며 기본 1분마다 갱신한다. 만료는 브라우저에서 매초 확인하므로 다음 조회까지 기다리지 않는다. 연결 실패 시 즉시 마지막 정상값으로 돌아간다. 추정값을 브라우저 영구 저장소에 보관하지 않는다.
- 추정과 마지막 값 유지 중에는 “현재 온도는” 음성을 대기한다. 정상 최신값을 수신하면 다음 음성 주기에 재개한다.
- `GET /api/trend`는 실측 `bars`, 정상/실패 수, 실측 최저/최고를 유지하고 `estimates` 배열을 별도로 반환한다. 실제 저장된 OCR 실패 시각에만 당시까지의 정상값으로 추정한다. 측정 기록 자체가 없는 구간은 채우지 않는다.
- 1/5/10분봉 모두 추정은 주황 점선·빈 원으로 표시한다. 추정값을 정상 봉이나 실측 최저/최고에 합산하지 않는다. 추정이 축 밖으로 잘리지 않도록 세로축 표시 범위에는 포함한다.
- 그래프는 조회 시작 이전 최대 6분을 근거로 읽을 수 있으나 보관 경계를 넘지 않는다. 이 때문에 자정 근처 24시간 조회는 최대 3개 날짜 색인을 읽는다.

## 검증 범위

합성 데이터로 선형/보합/하락·천 단위·음수, 조건 불충족, 120초 경계, 장치 혼합, 원본 보존, 자정, 색인 갱신, UI 만료/복귀/음성 대기를 검사한다. 실제 HMI 원본과의 추정 오차는 현장 자료로 별도 평가해야 한다. 이번 변경으로 OCR 엔진의 인식률이 높아졌다고 주장하지 않는다.
