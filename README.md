# TC-06 온도 OCR · 현장 음성 모니터

윈도우 PC의 HMI 영상에서 **TC-06 표시 온도**를 읽고, **1분마다 서버에 저장**합니다. 현장 TV 브라우저에서는 온도를 크게 표시하고 한국어 여성 음성으로 **“현재 온도는 … 도입니다.”**를 1분마다 안내합니다.

**웹/API · Windows 수집기 0.6.0.** Python·OCR 엔진을 포함한 Windows 설치판을 제공합니다. 실제 장치·고온 HMI·TV 재생과 빌드/설치 자동 검사는 [검증 문서](docs/VERIFICATION.md)에서 구분합니다.

## Windows에서 설치해 사용

[v0.6.0 릴리스](https://github.com/esp6662266/tc06-temperature-monitor/releases/tag/v0.6.0)의 **TC06Monitor-Setup-0.6.0-x64.exe**를 받습니다. Windows 10/11 x64 대상이며 Python·Tesseract·영문 데이터 설치가 따로 필요 없습니다. 바탕화면의 TC-06 Monitor를 열고 영상 입력만 설정하세요. [설치 안내](docs/WINDOWS_INSTALL.md)를 참고하세요. 캡처보드 드라이버는 장치에 따라 필요합니다.

## OCR 복구와 원격 업데이트

실패 시 새 화면으로 재판독하고 실패 원인과 작은 온도 영역 캡처를 PC에 제한 보관합니다. 실패 기록 후 정상으로 돌아오면 확인된 실제값을 즉시 저장합니다. [업데이트 관리](https://tc06-temperature-monitor.netlify.app/updates.html)에서 PC 버전·연결 상태를 확인하고 명시적으로 적용합니다. 서명·해시 검증 후 수집기만 교체하며 실패 시 이전 버전으로 복구합니다. 기존 0.5.0 PC는 최초 한 번 0.6.0 설치가 필요합니다. [연결·복구·다음 릴리스 안내](docs/UPDATES.md)를 참고하세요.

- **온도 추이 그래프:** https://tc06-temperature-monitor.netlify.app/?mode=graph

- **수집 PC 서버 주소:** `https://tc06-temperature-monitor.netlify.app` (GUI 기본값에 포함)

홈페이지는 검은 배경에 큰 숫자와 실측 여부·경과 시간을 표시합니다. 화면 클릭·터치 또는 리모컨 Enter로 메뉴를 열고 **음성 시작 / 전체 화면 / 일반 화면 / 그래프 / 설정**을 선택합니다. Esc로도 일반 화면에 돌아갑니다. 메뉴는 조작 후 5초가 지나면 숨겨집니다. CSS가 화면을 채우며 브라우저 주소창까지 숨기는 전체 화면은 조작이 필요할 수 있습니다.

짧은 OCR 실패에는 안정적인 최근 정상값 3~5개로 마지막 실측 후 최대 2분까지만 추정값을 표시합니다. `≈605.0 · 추정값 · 마지막 실측 1분 전`처럼 구분하며 실측 기록으로 저장하지 않습니다. 조건과 한계는 [추정 정책](docs/ESTIMATION.md)을 참고하세요.

추정 조건이 안 맞거나 인터넷 단절·영상 정지·캡처 후 150초 초과 때는 **마지막 정상 온도**를 유지하고 **“마지막 정상값 · 7분 전”**처럼 원래 판독 시각부터 지난 시간을 표시합니다. 숫자 전용·일반·그래프 상단 모두 적용하며 시간이 지나면 문구도 갱신됩니다. 서버에도 보관하므로 새 브라우저에서 복원되며, 브라우저에 보관한 값은 API 단절 중 새로고침에도 유지됩니다. 모두 한국 날짜 기준 최근 30일 범위만 사용합니다. 정상 수신이 재개되면 최신 온도로 돌아갑니다. 웹 표시 정책은 홈페이지 새로고침으로 적용됩니다. OCR 복구·원격 업데이트는 새 Windows 설치판이 필요합니다.

추정값과 과거 값을 “현재 온도”로 읽지 않도록 추정·마지막 값 유지 중에는 음성 안내가 대기하고 정상 수신 후 다음 주기에 재개됩니다. 보관된 정상 이력이 없거나 만료됐을 때만 **기본 표시값 38도**를 표시하며, 음성은 “수신 이력이 없습니다. 기본 표시값은 38도입니다”로 구분합니다. 최초 API 조회가 끝나기 전에는 숫자 대신 —와 불러오는 중을 표시합니다. 추정값·유지 값이나 기본 38도로 새 측정 기록·그래프 봉을 생성하지 않습니다. 추정은 그래프에 별도 점선·빈 원으로 표시하며 실측 최저/최고 통계에서 제외합니다.

음성 시작을 한 번 누르면 정상 최신값 또는 기본값을 안내하고 기본 1분마다 반복합니다. 추정·마지막 정상값 유지 상태에서는 대기합니다. 일반 화면의 접힌 **화면 · 음성 설정**에서 음량·반복 간격(1/2/5분)·색상 조합(현장 추천 7가지·직접 선택)·크기를 바꾸며, 이 기기의 브라우저에 저장됩니다. 브라우저가 허용하지 않는 무조작 소리 재생을 강제하지 않습니다.

오프라인 페이지·고정 음성 자산은 **온라인으로 한 번 정상 방문하고 서비스 워커 캐시가 저장된 브라우저**에서 사용할 수 있습니다. 캐시 삭제·시크릿 모드·서비스 워커 미지원 TV에서는 오프라인 첫 접속을 보장하지 않습니다. API 응답은 서비스 워커로 캐시하지 않습니다. 별도 브라우저 저장소의 마지막 정상값에는 경과 시간을 붙여 과거 값임을 표시합니다.

## 웹 화면 개선 (0.6.0 UI 1)

- 일반·숫자·그래프 화면에 실측/추정/마지막 정상값/기본 표시값을 구분하고 원래 캡처 시각부터 경과 시간을 표시합니다. 서버 연결과 판독 상태도 구분합니다.
- 일반 화면의 설정·표시 정책은 접어서 열고, 색상은 7개 조합과 직접 선택을 하나의 메뉴에서 고릅니다. 색상·크기는 숫자 전용 화면에만 적용됩니다.
- 그래프 아래 **판독 상태 띠**는 실측/실패/혼합/기록 없음과 추정 표시를 온도 축에서 분리합니다. 실측 기록과 실패 기록은 별개 집계이며 재시도 횟수·OCR 정확도가 아닙니다. 누르기·좌우/Home/End 키로 상세 툴팁을 확인합니다.
- **세로축 · 참고 온도 설정**에서 자동/고정 축과 목표·참고 범위를 설정합니다. 기본은 자동 축·참고선 꺼짐입니다. 고정 축 밖 온도/참고선은 경고하고 실측 최저·최고 통계는 유지합니다. 설정은 해당 브라우저에 저장되며 설비 설정에 영향을 주지 않습니다.
- 웹만 변경합니다. Windows 설치판 0.6.0, 업데이트 관리 화면·인증·접속 방식은 유지합니다.

## 구성

```text
HMI 영상
  ├─ 캡처보드 원본 직접 읽기 (권장)
  └─ 지정한 창의 보이는 영역 읽기 (이동·크기 변경 추적)
              ↓
Windows 수집기: 로컬 OCR · 원본 시계 확인 · SQLite 기록/재전송
              ↓ HTTPS, 1분마다
Netlify Functions + Blobs: 공개 수신 · 기록 저장 · 최신값 순서 보호
              ↓
현장 TV: 브라우저 화면 · 고정 숫자 조각을 Web Audio로 합성
```

- 외부 AI API와 유료 OCR/TTS API를 호출하지 않습니다. OCR은 로컬 Tesseract, 음성은 웹 전용 숫자 합성기를 사용합니다.
- 한국어 여성 목소리의 숫자·단위와 기본값 안내 MP3 18개(합계 **87,402바이트, 약 87KB**)를 재사용합니다. 123.4는 백·이·십·삼·점·사·도입니다 순서로 웹에서 조합합니다. Windows/TV에 한국어 TTS를 설치할 필요가 없으며 `speechSynthesis`에 의존하지 않습니다. 재생에는 Web Audio와 MP3 지원 브라우저가 필요합니다.
- 음성 조각을 이어 붙이는 특성상 문장 전체 TTS보다 억양이 끊길 수 있습니다. 온도마다 음성 파일을 생성하거나 서버에 누적하지 않습니다.
- 서버 호스팅·함수 호출·저장소 사용량은 Netlify 요금제에 따릅니다. 무료 무제한을 보장하지 않습니다.
- PLC에 접속하거나 HMI를 조작하는 기능이 없습니다. 영상 표시값의 참고 감시 도구이며 설비 보호·인터록·비상 경보를 대체하지 않습니다.

## 사용 범위와 제한

- **지정한 HMI 영상 안에서** 추적합니다. 바탕화면의 아무 숫자나 온도로 읽지 않습니다.
- 창 방식은 **보이는 화면 캡처**입니다. 옆에 다른 창이 있는 것은 가능하지만, TC-06 또는 원본 시계가 가려지거나 HMI 창이 최소화되면 정상 판독을 보장하지 않습니다. 이때 판독 불가로 처리합니다. 가림 판정은 픽셀 격자 표본이므로 모든 투명 오버레이를 완벽히 검출한다고 주장하지 않습니다.
- 캡처보드 직접 입력은 미리보기 창 위치와 무관합니다. 캡처 장치가 다른 앱에 독점되면 해당 앱을 종료하거나 장치 공유 구성을 실제 확인해야 합니다.
- 첨부된 HMI처럼 **검은 라벨 + 바로 오른쪽의 회색 숫자칸 + 오른쪽 단위 + 화면 상단 시계**를 대상으로 합니다. 다른 테마·배치·아주 작은 창은 OCR 프로필 수정이 필요합니다.
- 화면 상단에 단 하나의 `시:분:초`가 검출되어야 합니다. 시계가 약 15초 정지하면 `stale_source`입니다. 이는 영상 진행 확인이며, 원본 HMI의 PLC 통신 품질까지 증명하지 않습니다.
- 웹은 캡처 후 150초 이내 정상값만 최신 수신값으로 표시합니다. 통신·판독 실패와 오래된 값은 마지막 정상값에 경과 시간을 붙이고 음성을 대기합니다. 이 동작은 OCR 정확도를 높이거나 미수집 온도를 복원하는 기능이 아닙니다.
- 음성은 페이지를 열고 **‘음성 안내 시작’**을 눌러야 할 수 있습니다. 이는 로그인 조건이 아닌 브라우저 자동재생 정책입니다. 실제 TV의 Web Audio·MP3·JavaScript·소리 재생 지원을 확인해야 합니다. 백그라운드 탭·절전 상태에서 60초 타이머의 정확한 실행을 보장하지 않습니다.
- PC 절전·종료 중에는 측정하지 않습니다. 복귀 후 빠진 분의 온도를 추정해 채우지 않습니다.
- 기본 GUI는 단일 수집기만 실행하세요. 한 사이트는 한 대의 수집 PC/TC-06을 대상으로 합니다.
- 서버는 **한국 날짜 기준 오늘을 포함한 최근 30일**만 보관합니다. 매시 15분에 지난 날짜 기록과 이전 서버 음성 파일을 정리합니다. 한 실행은 최대 2,000개·약 22초이며 남으면 다음 시간에 계속합니다. 만료 기록 재전송과 조회는 즉시 거부합니다. PC SQLite 이력은 별도이며 자동 삭제하지 않습니다.

## 개발 검증

Python 3.12 권장, Node.js 22 이상. Windows EXE는 Windows에서만 빌드합니다.

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
npm ci
npm test
npm run test:web
```

웹 시험은 설치된 Chrome을 사용합니다. Chrome이 없으면 Playwright 설정을 환경에 맞춰 변경해야 합니다. 테스트 화면의 수치는 합성된 예시이며 실설비 운전 데이터가 아닙니다.

## 공개 저장소에 포함하지 않는 것

실제 운전 화면, 온도 기록, 사용자별 설정, 빌드 중간 파일은 `.gitignore`로 제외합니다. 온도 사이트와 수신 API는 사용자 요청에 따라 모두 공개·무인증입니다. 서버 주소만 알면 조회와 업로드가 가능합니다. `web/voice/*.mp3`는 고정 숫자 음성 배포 자산입니다.

일반 화면의 **전체 화면** 버튼도 숫자 전용 모드로 전환한 후 전체 화면을 요청한다. 정상 수신 중에는 제목·상태·단위·설정을 숨기며, 마지막 정상값 유지 중에는 경과 시간 문구를 함께 표시한다. 화면/리모컨 조작 때만 메뉴를 잠깐 표시한다.

현장 색상 미리보기 7가지: 검정/흰색, 검정/노랑(추천), 검정/민트, 검정/하늘색, 검정/주황, 남색/흰색, 노랑/검정. 앞은 배경, 뒤는 숫자색이다. 밝은 대비를 기준으로 고른 디자인이며 실제 현장 조명·거리·TV에서 최종 선택한다.

## 음성 묶음과 보관 정책

일반 실행·Windows 설치에는 음성 생성 도구가 필요 없습니다. 묶음을 새로 만드는 개발 작업에만 macOS의 Yuna와 ffmpeg를 사용합니다. `python3 scripts/build-number-voice.py`로 고정 자산을 생성하고 음질·크기·웹 시험을 확인한 뒤 배포합니다. 실행 중에는 동봉 자산을 사용하므로 OS 한국어 음성 설치 여부와 무관합니다.

서버는 `{record: ...}` 텍스트 JSON만 저장합니다. 이전 수집기의 음성 필드는 무시합니다. `/api/retention`에서 정책과 최근 정리 결과를 확인할 수 있습니다. 한국시간 10월 16일이면 9월 17일~10월 16일 기록을 남깁니다. 필요한 CSV는 만료 전에 다운로드하세요. 기본값 38은 실제 측정 이력으로 만들지 않습니다.

## 추가로 확인된 OCR 한계

v0.4에서 재현된 38.0→58.0, 350.0→550.0, 550.0→950.0 오독과 999.9 판독 실패를 v0.4.1 합성 회귀 시험에서 개선했습니다. 숫자 회색조를 보존해 여백·확대 처리를 바꾸고 서로 다른 Tesseract 분할 방식의 문자열 일치와 원본 픽셀 자릿수/소수점을 대조합니다. 시작·복구 또는 값이 크게 바뀔 때는 원본 시계가 진행한 다음 화면에서 한 번 더 확인하며, 미확인 값은 정상 온도로 저장하지 않습니다.

두 방식은 여전히 같은 OCR 엔진이므로 **오독 0%나 현장 정확도를 보장하지 않습니다.** 흐림·작은 글씨·붙은 숫자를 더 보수적으로 거부해 판독 불가가 늘어날 수 있습니다. 900도 이상·네 자리 숫자도 허용하지만 모든 숫자를 항상 읽는다는 뜻은 아닙니다. [OCR 보완과 검증 범위](docs/OCR_VALIDATION.md)를 읽고 실제 HMI 글꼴·해상도에서 원본 대조를 진행하세요. 웹사이트 재접속만으로 수집기 OCR이 바뀌지는 않으며, 수집 PC에서 최신 소스를 받아 다시 실행해야 합니다.

## 온도 추이 그래프

일반 화면의 **온도 그래프** 또는 숫자 화면 메뉴의 **그래프**로 들어갑니다. 직접 주소는 `?mode=graph`이며 `&minutes=5&span=360`처럼 초기 5분봉·6시간 범위를 지정할 수 있습니다.

상단에는 실제 최신 온도와 수신 시각을 크게 표시합니다. 짧고 안정적인 추세의 OCR 실패에는 별도 추정값을, 그 외 단절/실패/오래된 값에는 마지막 정상 온도와 경과 시간을 표시하고 사유를 구분합니다. 정상 이력이 없을 때만 기본 38도입니다. 그래프에는 **서버에 저장된 정상 기록만** 사용하며 유지 값이나 기본 38도, 실패 기록을 새 온도 값으로 채우지 않습니다.

- 1분봉/5분봉/10분봉: 각 구간에서 저장된 첫값·최고·최저·마지막 값을 표시합니다.
- 수집은 1분 간격이므로 1분봉은 대개 한 점으로, 첫값·최고·최저·마지막이 같습니다. 분 사이의 온도를 추정하거나 실제 미수집 최고값으로 표시하지 않습니다.
- 최근 1시간/6시간/24시간과 기준 날짜를 선택합니다. 오늘은 현재 시각까지 이전 날짜를 이어 조회하고, 과거 날짜는 그날 자정 종료 기준입니다. 과거 날짜 선택 시 24시간으로 전환합니다.
- 1분마다 갱신하며 세로축은 조회 구간의 최저·최고에 맞춰 자동 조절합니다. 900도도 자동 범위 안에 표시됩니다.
- 봉을 클릭·터치하거나 차트에 포커스를 두고 좌우/Home/End 키를 누르면 상세를 봅니다. 아직 끝나지 않은 마지막 봉은 진행 중으로 표시합니다.
- 실패만 있는 구간은 아래쪽 실패 표식, 기록 없음은 빈 구간입니다. 정상값이 없는 시간대를 선으로 잇지 않습니다.
- 연결 실패 시 마지막 조회 그래프는 남기고 단절 상태를 표시합니다. 새로고침한 오프라인 페이지에는 이력이 자동 복원되지 않습니다.

서버는 `trend/한국날짜`에 재전송 id로 중복 제거한 작은 그래프 색인을 유지합니다. 예전 이력은 처음 조회할 때 한 번 색인으로 옮기고 이후에는 수천 개 이력 파일 대신 날짜별 색인을 읽습니다. 색인도 서버 기록과 같은 30일 정책으로 삭제합니다. 별도 외부 차트 서비스는 사용하지 않습니다.
